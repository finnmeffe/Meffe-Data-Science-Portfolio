# Federal R&D Spending Analysis
 
## Project Overview
This project analyzes US federal R&D spending across government departments from 1976–2017. The goal was to clean and reshape the data following tidy data principles, then visualize the results. Generally, the main features of tidy data are as follows:
- Each variable is in its own column
- Each observation forms its own row
- Each type of observational unit forms its own table
 
## Dependencies

pip install pandas matplotlib

## How to Run
1. Open the `.ipynb` file in VS Code
2. Select the correct Python kernel
3. Run each cell in order from top to bottom
